# Fonts

The Deck frontend draws text with these Noto fonts (SIL Open Font License 1.1, see `OFL.txt`; copyright the Noto
Project Authors), copied unmodified from Fedora's `google-noto-*-fonts` packages:

| File | Used for |
| --- | --- |
| `NotoSans-Condensed.ttf`, `NotoSans-CondensedBold.ttf` | Labels (Android uses Roboto Condensed) |
| `NotoSansMono-Regular.ttf`, `NotoSansMono-Bold.ttf` | Grid values; first fallback (arrows, ▴▾◀▶, ‖) |
| `NotoSansSymbols2-Regular.ttf` | Fallback for ✓ ✛ |
| `NotoSansMath-Regular.ttf` | Fallback for ↻ ↺ |
