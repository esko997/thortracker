# Getting started

Begin with the bundled **Thor Groove** demo. Press **Start** to play or stop it, then save a named copy before experimenting. If the app has recovered an earlier working document, save that first; choosing a demo replaces the working song.

## Find your way around

1. Open the menu with **Select + Start** (or **Menu** on Brick). On Android the chord reveals the toolbar.
2. Choose **Files → New blank song** and select a sound system, or **Load demo** to explore a system with notes and instruments already in place.
3. Use the **D-pad** to move through the pattern. **Hold A + D-pad** edits a value; **B** clears. **L2 + A** undoes an edit and **L2 + B** redoes it.
4. **Start** plays or stops. Hold **X** to listen without writing. Consult the view's hints and the [complete controller table](/controls/) for the current context.

Button names refer to the app's logical controls. Handheld labels and Steam Input layouts can differ; **Menu → Controls** lets you rebind them. On Android without a usable controller, the touchscreen dock supplies the D-pad, face buttons and modifiers; its navigation drawer provides view switching and commands. Connecting a controller hides the dock.

## A first session on Brick

1. Open **Tools → ThorTracker**. Start/stop the demo with **Start**.
2. Open **Select + Start → Files → Save as…** and keep a named copy before editing.
3. In Pattern, change a note with **A + direction**, listen with **X**, then undo with **L2 + A**.
4. Use **R2 + B** for Instrument. Keep the Sound face for musical controls or switch
   to Advanced for the chip's detailed settings. Both edit the same instrument.
5. Save the project before exporting; choose the format offered for that sound system.
6. **Select + Start → Quit** returns to NextUI. Projects and exports are under
   `/mnt/SDCARD/ThorTunez`, outside the replaceable Pak.

If a sound is silent, check its channel/instrument compatibility and the
[troubleshooting guide](/troubleshooting/) before changing device-wide audio settings.

## Keep the result

Use **Files → Save as** to keep an editable `.thor` project. Use named versions for milestones: the single previous-project recovery slot is replaced again when you open another project, load a demo or start a blank song.

Next: [controller shortcuts](/controls/), [system-specific instruments](/systems/), or [save and export formats](/files/). The [complete manual](/manual/) also covers scales, pattern lengths, polyrhythms and microtuning.
